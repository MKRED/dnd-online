# Эффекты на персонаже

Живой план. Отмечаем этапы по мере готовности.

## Что делаем

Игрок накладывает на своего персонажа эффекты из каталога: «Ускорение», «Схваченный», «Тёмное зрение». Лист сам пересчитывает то, что эффекты меняют, и одной кнопкой переключается между двумя видами (пожелание пользователя 2026-10-17):

- **«С эффектами»** — итог: Скорость 60 фт. под «Ускорением»;
- **«Без эффектов»** — база: то, что введено в форме.

Что уже решено раньше ([abilities-effects.md](abilities-effects.md), «Связь с персонажем»):

- эффекты накладывает владелец персонажа, мастер — когда появятся сессии;
- наложенные эффекты видны **полосой плашек вверху листа**, а не на отдельной вкладке.

## Решения

Согласованы с пользователем 2026-10-17.

### База и итог (пробел М)

- **Числа из формы — это база.** Колонки `armor_class` и `speed` не меняются, миграции листа нет. Итог хранить не нужно: его считает `shared` при показе, по базе и эффектам.
- В форме у Скорости и КД подпись «без эффектов».
- Сейчас движок умеет только Скорость (`totalSpeed`). КД появится с составляющей 7.6, бонусы к броскам — с 7.5. Остальные составляющие лист пока только перечисляет (ниже).

### Что меняется в режиме «С эффектами»

| На листе                         | Откуда                                                            |
| -------------------------------- | ----------------------------------------------------------------- |
| Скорость, особые скорости        | `totalSpeed`: число пересчитано                                   |
| Состояния                        | плашки, в том числе включённые (Бессознательный → Опрокинутый)    |
| Сопротивления и иммунитеты       | список «Защита»                                                   |
| Чувства                          | список «Чувства»                                                  |
| Преимущество, помеха, автопровал | список «Броски»: «Помеха на атаки», «Автопровал спасбросков Силы» |
| Запрет лечения, урон за ход      | строка у ХП                                                       |

- **Изменённое число выделено** цветом и значком. Подсказка объясняет: «Без эффектов 30 фт. Ускорение: ×2».
- **В режиме «Без эффектов»** списков «Защита», «Чувства» и «Броски» нет, числа — из формы. Полоса плашек остаётся: по ней видно, что эффекты есть.
- **Переключатель показываем, только если эффекты есть.** Режим по умолчанию — «С эффектами». Режим не запоминаем: при открытии листа снова итог.

```
┌ Арвен ────────────────────────────── [Изменить] ┐
│ [Ускорение ✕] [Схваченный ✕] [+ Эффект]          │
│ Вид листа: ( С эффектами | Без эффектов )        │
├──────────┬──────────┬──────────┐                 │
│ ХП 24/30 │ КД 15    │ Инициатива +2              │
│ Скорость │ Бонус ма │ Кость хитов                │
│ 0 фт ●   │ +2       │ к8                         │
└──────────┴──────────┴──────────┘                 │
│ Броски: помеха на атаки, кроме атак по наложившему │
```

### Хранение

Ссылка на запись каталога, как у инвентаря ([character-inventory.md](character-inventory.md)):

```
character_effects
  id            uuid PK
  character_id  uuid → characters.id  ON DELETE CASCADE
  effect_id     uuid → effects.id     ON DELETE SET NULL   -- null: «Эффект удалён автором»
  added_at      timestamptz                                -- порядок плашек
  UNIQUE (character_id, effect_id)                         -- эффект на персонаже один раз
  INDEX (effect_id)
```

- **Один эффект — один раз.** Решено с пользователем 2026-10-17: по книге одно и то же заклинание не складывается, второй экземпляр ничего бы не дал. Повторное наложение — 409 «Эффект уже наложен». Исключение книги — Истощение, оно копится; уровень у плашки («Истощение 2») появится с пробелом И, отдельным полем строки, а не второй строкой.
- **Оставшаяся длительность не хранится.** Ходов и раундов в приложении ещё нет. На плашке — длительность из карточки («1 минута, концентрация»), снимает эффект игрок. Счётчик появится с боем на карте.
- **Скрытый и удалённый эффект** — как предмет: плашка «Эффект скрыт автором» или «Эффект удалён автором», её можно только снять, и **на лист она не действует**. Зритель по ссылке видит эффекты по своему доступу к карточкам, как предметы.

### API

Менять может только автор персонажа, отдельно от формы:

- `GET /characters/:id` отдаёт `effects`: строки с карточкой эффекта или `effect: null` и `state: 'hidden' | 'deleted'`.
- `POST /characters/:id/effects` — `{ effectId }`. Эффект должен быть виден автору персонажа.
- `DELETE /characters/:id/effects/:entryId`.

### Вычисление

Одна чистая функция в `shared`: `sheetTotals(character, effects)` → итоговые числа, списки и для каждого изменённого числа — какие эффекты его изменили (для подсказки). Ей пользуется лист, потом сервер в игре. Собирается из того, что уже есть: `expandConditions`, `totalSpeed`.

## Этапы

- [ ] **1. Сервер.** Таблица `character_effects` (миграция — с разрешения пользователя), три маршрута, `effects` в ответе листа. e2e: наложить, снять, повтор — 409; доступ (аноним 401, чужой 404, зритель по ссылке видит, но не меняет); чужой скрытый эффект — 404 при наложении, плашка «скрыт» после скрытия; удалённый — «удалён».
- [ ] **2. Вычисление.** `sheetTotals` в `shared` с тестами: Скорость под Haste и Схваченным, скрытый эффект не действует, списки защиты, чувств и бросков без повторов, объяснение «почему».
- [ ] **3. Плашки.** Полоса плашек на листе, окно «+ Эффект» с поиском по своим и опубликованным, снятие. Компонентные тесты, проверка в браузере.
- [ ] **4. Два вида листа.** Переключатель, выделение изменённого, подсказка, списки. Подпись «без эффектов» в форме. Компонентные тесты, проверка в браузере: светлая и тёмная схемы, 390 px.
- [ ] **5. Прод.** Деплой с разрешения пользователя.

## Открытые вопросы

- ~~**Где переключатель.**~~ Строкой над плитками боевых чисел: он меняет в первую очередь их. Решено с пользователем 2026-10-17, можно поправить после проверки в браузере.
- ~~**Запоминать ли режим.**~~ Нет, лист всегда открывается итогом: в игре нужен он. Решено с пользователем 2026-10-17.
- ~~**Особые скорости и чувства в базе.**~~ «Без эффектов» значит буквально без них: в базе все персонажи обычные, Тёмное зрение эльфа — бессрочный эффект ([effects.md](effects.md)). Решено с пользователем 2026-10-17.
