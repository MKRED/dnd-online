## Что осталось

Хвосты закрытых планов, отложенные «на потом». Подробности — по ссылке.

**Карта, отложенное из этапов 5–6** ([map.md](map.md)):

- редактор: оптимистичное применение операций, выделение и копирование, префабы, правки других участников вживую;
- путь: лазание, прыжки, падение, протискивание, существа на пути, частичные фигуры;
- подсветка пути, радиуса, области и целей в рендере.

**Предметы** ([done/items.md](done/items.md), «Категории»):

- категории 7–14: зелье, свиток, инструмент, заклинательная фокусировка, боеприпас, щит, доспех, оружие; признак «Магический»;
- готовый каталог предметов из книги; экипировка и взаимодействие на карте — вместе с игрой;
- предмет из чужого набора не может стать набором ([done/item-packs.md](done/item-packs.md), «Открытые вопросы»).

**Способности** ([done/abilities.md](done/abilities.md), «Открытые вопросы» и «Не берём» в этапах):

- состояние в шаге напрямую, без эффекта-обёртки;
- вид действия (Атака, Магия…) для «Всплеска действий»;
- условие реакции — выбор события вместо текста, вместе с боем на карте;
- рост эффекта и числа целей с ячейкой; рост с уровнем класса; списки классов у заклинания.

**Эффекты** ([done/effects-coverage.md](done/effects-coverage.md), «Предлагаемый порядок», п. 7): вместе с картой — ограничения действий, крит вблизи, «не видит и не слышит», конец по событию, уровни, подавление, эффект по окончании, ауры.

**Персонажи:**

- картинки: порядок перетаскиванием, подписи, вставка из буфера и по ссылке, портрет на токене ([done/character-images.md](done/character-images.md), «Позже»);
- инвентарь: вес монет, доступ к хранилищу с разрешения мастера ([done/character-inventory.md](done/character-inventory.md), «Открытые вопросы»);
- способности: магия договора колдуна (свои ячейки после короткого отдыха), сортировка внутри группы — по порядку добавления или по названию ([done/character-abilities.md](done/character-abilities.md), «Открытые вопросы»).

**Закладки** ([done/bookmarks.md](done/bookmarks.md), «Открытые вопросы»): карты в закладках, звёздочка в списках каталога, предел числа закладок, папки и заметки.

**Вход через лольку** ([done/lolka-login.md](done/lolka-login.md), этапы 5–6): привязка лольки к существующему аккаунту; мгновенный вход внутри каталога лольки.

**Тесты** ([done/testing.md](done/testing.md)):

- проверка прода после деплоя (этап 5, «может быть, не нужна»);
- ускорение прогона, если станет долгим;
- браузерные тесты на Playwright Test — отдельный план.
